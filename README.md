# HebrewLearnBot

Телеграм-бот для запоминания слов иврита. Показывает слово, даёт четыре варианта ответа инлайн-кнопками и подсвечивает результат: правильный вариант зелёным, ошибочный выбор — красным.

## Режимы квиза

| Режим | Вопрос | Варианты на кнопках | Транскрипция в разборе |
|---|---|---|---|
| Иврит → русский | слово на иврите | русские переводы | нет, нигде |
| Транскрипция → русский | транскрипция латиницей | русские переводы | была в самом вопросе |
| Русский → иврит + транскрипция | русское слово | `שולחן (shulkhan)` | да |
| Русский → иврит | русское слово | только иврит | да, раскрывается после ответа |

Тренировка бесконечная: вопросы идут подряд, пока не нажать «⏹ Стоп», после чего бот показывает сводку и список слов, в которых были ошибки.

Слова подбираются с весами: новые и те, где были ошибки, выпадают заметно чаще давно выученных.

## Квиз по алфавиту

Кнопка «🔤 Алфавит» (или `/alphabet`) — отдельная бесконечная тренировка: бот показывает букву, нужно выбрать её название из четырёх вариантов. Работает как словарный квиз (те же «⏭ Пропустить» / «⏹ Стоп», тот же принцип подбора вопросов по весам), но без выбора режима и темы — направление всегда «буква → название».

31 вопрос: 22 буквы алефбета, 4 из которых (בּ/ב, כּ/כ, פּ/פ, שׁ/שׂ) показываются в двух огласованных вариантах — с дагешем/точкой и без, так как без диакритического знака они неразличимы, — и 5 конечных форм (софитов: ך ם ן ף ץ). Прогресс и статистика по буквам не связаны со словарными — оба раздела показываются вместе командой `/stats`.

## Квиз по числам

Кнопка «🔢 Числа» (или `/numbers`) открывает отдельный раздел с женскими формами числительных от 0 до 99. Импорт словаря для него не нужен.

| Тренировка | Диапазон | Как отвечать |
|---|---|---|
| Карточки | 0–99 | Четыре варианта: иврит → число, транскрипция → число, число → иврит с транскрипцией или без неё |
| Ввести число | 0–99 | Название на иврите или транскрипция; ответ — число сообщением |
| Число → иврит | 0–10 включительно | Шесть вариантов названия на иврите без транскрипции |

После ответа бот показывает число, написание на иврите и транскрипцию. В режиме ввода принимаются цифры `0`–`99`; посторонний текст, отрицательные и дробные числа не засчитываются, вопрос остаётся активным. «⏭ Пропустить» показывает ответ, «⏹ Стоп» завершает тренировку со сводкой и списком ошибок.

Прогресс чисел хранится отдельно от словаря и алфавита, по каждому режиму. Новые числа и числа с ошибками выпадают чаще; недавние вопросы исключаются из подбора. Команда `/stats` также показывает общую статистику по числам.

## Быстрый старт

```bash
cp secrets.env.example secrets.env
# заполните BOT_TOKEN (от @BotFather) и MAIN_ADMIN_ID (ваш id, узнать у @userinfobot)

docker compose up --build
```

Проверка, что бот жив: `curl http://localhost:8182/health`.

### Запуск без Docker

Нужен .NET 10 SDK и работающий PostgreSQL.

```bash
docker compose up -d postgres          # или свой локальный postgres
dotnet run --project src/HebrewLearnBot.Worker
```

Контейнер postgres слушает на хосте порт **5433** (5432 обычно занят локально установленным
PostgreSQL), поэтому в `secrets.env` для запуска с хоста нужны `POSTGRES_HOST=localhost` и
`POSTGRES_PORT=5433`. В compose сервис `bot` переопределяет их на `postgres:5432`, так что
один и тот же `secrets.env` годится для обоих способов запуска.

Файл `secrets.env` ищется вверх по дереву каталогов от каталога сборки, поэтому
`dotnet run --project ...` работает из корня репозитория без копирования файла.

Проверка: `curl http://localhost:8080/health`. Миграции применяются автоматически при старте.

## Загрузка словаря

Отправьте боту CSV- или TSV-файл документом (кнопка «📥 Импорт словаря» — видна только пользователю с `MAIN_ADMIN_ID`). Готовый стартовый словарь на 61 слово лежит в [`samples/words-starter.csv`](samples/words-starter.csv).

### Формат файла

Первая строка — заголовок. Порядок колонок произвольный, регистр не важен, разделитель определяется автоматически (`,`, `;` или табуляция). Кодировка — UTF-8; файлы из Excel в windows-1251 тоже читаются.

| Колонка | Алиасы | Обязательная | Ограничения |
|---|---|---|---|
| иврит | `hebrew`, `he`, `иврит` | да | ≤ 100, хотя бы одна буква алефбета |
| никуд | `vocalized`, `никуд`, `огласовки` | нет | ≤ 200 |
| транскрипция | `translit`, `transliteration`, `транскрипция` | да | ≤ 100, только латиница, пробел, `'`, `-` |
| перевод | `ru`, `translation`, `перевод` | да | ≤ 200 |
| тема | `topic`, `category`, `тема` | да | ≤ 100, создаётся автоматически |
| род | `gender`, `род` | нет | `м`/`ж`/`m`/`f`/`мужской`/`женский`, только у существительных |
| часть речи | `pos`, `часть_речи` | нет | `сущ`/`гл`/`прил`/`нареч`/`фраза`, по умолчанию `сущ` |
| ключ | `key`, `external_key` | нет | ≤ 64, стабильный идентификатор строки |

```csv
hebrew;vocalized;translit;ru;topic;gender;pos;key
שולחן;שׁוּלְחָן;shulkhan;стол;Дом;м;сущ;home-001
דלת;דֶּלֶת;delet;дверь;Дом;ж;сущ;home-002
```

Огласовки хранятся отдельно от основного написания: в вопросах слово показывается без никуда, а в разборе после ответа — с ним.

### Повторная загрузка

Импорт делает upsert, а не дубликаты. Слово ищется по колонке `ключ`, а если её нет — по паре «иврит + перевод». Найденное обновляется, отсутствующее добавляется, ранее удалённое возвращается в оборот. Весь импорт идёт одной транзакцией: при ошибке база не меняется.

Лимиты по умолчанию — 1 МиБ и 5000 строк, настраиваются в `secrets.env`.

## Конфигурация

Все настройки — переменные окружения из `secrets.env` (см. [`secrets.env.example`](secrets.env.example)). Обязательные: `BOT_TOKEN`, `MAIN_ADMIN_ID`, `POSTGRES_HOST`, `POSTGRES_DB`, `POSTGRES_USER`.

Бот открыт всем: словарь общий, прогресс и статистика — у каждого свои. Импорт словаря доступен только пользователю с `MAIN_ADMIN_ID`.
